# MCP Inspector para Aion

Puedes usar MCP Inspector para probar las herramientas conectadas (GitHub, Netlify, X Ads, Automations).

Instala con:

npm install -g @modelcontextprotocol/inspector

Luego ejecuta:

npx @modelcontextprotocol/inspector

Conecta a los servidores MCP de GitHub, Netlify, etc. para inspeccionar y ejecutar acciones como crear repos, desplegar sitios o programar automatizaciones.
